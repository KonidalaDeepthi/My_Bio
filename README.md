# Konidala Deepthi — Portfolio

This is a clean, responsive personal portfolio website built with plain HTML, CSS, and JavaScript. It is GitHub Pages compatible.

How to use

- Edit `index.html` to add your real content (links, project details, resume).
- Place your profile image at `assets/profile.jpg` (recommended filename) or update the `img` src in `index.html`.
- You can use the included helper script to copy the file from your Downloads folder:

```powershell
.\copy_profile.ps1 "C:\Users\HP\Downloads\WhatsApp Image 2026-06-11 at 2.02.27 PM.jpeg"
```

If you run the script with no argument it will try the same default Downloads path.
- Update the email and social links in `index.html` and `js/main.js`.

Run locally

Open `index.html` in your browser.

Deploy to GitHub Pages

1. Create a new repository on GitHub and push the contents of this folder.
2. In the repository settings -> Pages, set the source to the `main` branch and `/ (root)` folder.
3. Save — your site will be available at `https://<your-username>.github.io/<repo-name>/`.
